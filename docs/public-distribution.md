# 分开下载与私人资料边界

普通使用先取电脑骨架ZIP或手机骨架APK。下方单独提供GERNZE_Codex插件ZIP，按需下载；骨架不含、不自动获取该插件。源码ZIP包括白名单里的通用源码，不是默认安装包。

私人升级APK包含作者已确认的本机人设与基础资料，只放本机热点发布器，不上传。公开骨架使用基础角色模板和空白第一层个人资料；第二至四层初始为空，API及配对由安装者自己设置。更新不以发行包覆盖已存在的本机数据库。

公开源码由source-files.json逐文件列出，.gitignore按同一清单生成。local-notes、完整人设、私人基础资料、所有运行数据库、密钥/证书、配对目录和私人发布配置都不在清单。建模环境、历史候选、手机调试/ADB私人工具不发布。完整人物资源与声音权重不在源码白名单，资源需按原授权取得；不能把本项目素材称为MIT素材。

Codex插件有独立安装/卸载入口与说明。首次启用后，宿主要求信任事件钩子；安装程序不自动信任，也不接管原有全局gernze连接。卸载保留个人资料和其它连接。手机任务提醒当前前台接收，锁屏与退后台暂停，不是后台即时推送。

不要用git add .；最后由作者运行项目根目录的“提交源码.cmd”，只暂存白名单文件并提交推送。发行二进制附件从干净公开发行目录上传，不能上传私人热点APK。当前没有自动上传动作。
