# 电脑自动记忆审查 · 本机接入状态

2026-10-22：旧来源/同步修复、自动审查事务修复与有限准入修复已三方接回源码，并重建、更新本机桌面快捷方式指向的EXE。已安装EXE在独立空白库完成启动、审核接口、开关保存和前端资源检查，正常退出。私人设定与基础资料校验未变，未操作真实记忆库。手机、真实提供方审核及用户实际资料链路仍未验；本文件不表示已在GitHub发布。

第一层仅用户授权修改；普通聊天和摘要API只能形成第三层待审资料。电脑的独立审核流程核对第三层及对应第四层来源，批准具体版本后进入第二层。审核模型不接收第一、二层正文，自动流程不改写、撤回或恢复既有第二层。

工作台运行期间每分钟检查排期，真正审核默认7天、最短1天；留空暂停定期审核。一次最多3条；失败不立即重试，工作台关闭停止。它不是Windows常驻服务或手机后台任务。

来源准备前后与审批事务内检查版本；手机来源范围绑定、完整性和角色归属均校验。审批及理由同事务，暂停/停止后旧结果失效。旧审批不能恢复已撤回的第二层。手机同步不接收手机提出的第二层写入，也不允许旧响应覆盖新的纠正。

当前自动晋级必须保留完整用户消息，1000字上限不变，再通过有限句式准入。明确小说、角色扮演、引文、假设及未支持的自由表达继续待审；这会漏收正常事实，不能称为通用语义辨认。没有任何标记且与本人自述完全相同的虚构内容无法保证识别；来源完整不证明现实真假。有限准入本身不额外调用模型；开启自动审查且有符合排期的候选时，独立审核仍会调用配置的聊天API并消耗相应额度。默认开启，可在电脑关闭。

实际Codex对话模型对12条合成消息做过一次归属评阅，能区分小说/视频作者与本人陈述。该结果不是生产审核适配器调用，也不是手机配置模型或隔离A/B，更不是统计准确率。旧36项测试和9组合成回放与本次合并回归分别记录。

接入复用SummaryAdapter、SQLite事务、MemoryLayers和现有同步协议；参考LangMem的提取/存储职责划分。没有安装新框架。正式接回须按补丁和基线哈希逐文件核对，不能用候选整目录覆盖私人资料或未列入本任务的源码。
