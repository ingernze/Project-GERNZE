## 1.1.2 本次变化

- 修复电脑记忆设置保存、重开和审查入口的问题。
- 修复独立审查等待过短；按作者要求保留高思考，仅把审查输出上限调为8192、等待上限60秒，增加安全结束原因/用量诊断。停止后旧结果仍不写入，不自动重试。
- 电脑审查失败增加安全的原因提示，区分连接超时、中断及结果格式或证据不符；旧记录无法追溯的原因保持未知，不自动重试付费请求。
- 电脑审查与手机下载共用银色进度条和原有小莉宝，填充端点跟随角色。审查按真实完成步骤与条数推进，等待及读取中断保持最后位置；下载按有效原生字节推进，不伪造模型耗时百分比。
- 审查完成后显示实际写入、保留待审和排除数量，按已提交的最终决定统计；模型提议被本地规则留待审时不会记成写入。
- 工作台默认进入人物场景；修复改名后头像缺图及旧六级可选模块无法加载，保留既有资料路径。
- 电脑API连接可以新增、查看数量、切换和移除；页面显示保存状态，不显示密钥内容。
- 书本未点击时贴住架板，保留点击展开和返回。
- 电脑设置右下角显示v1.1.2，滚动设置内容时仍可查看。
- 聊天优先保留完整近期对话，再补相关旧资料。电脑与手机有效长回复不再悄悄截为4000字符；超出本地上限、损坏的结构化输出或明确未完成的回复会报错。普通回复与有限中文规则识别的明确详述使用不同输出预算。
- 手机先显示、保存回复，再按到期规则整理旧对话；发送新消息时优先处理聊天。预算允许时可缩小整理批次，超限原文保留并显示原因，不跳过或假报完成；重开后保留阻塞状态。
- 电脑旧对话整理不再用单条4000字符门槛误拒长回复，仍受完整请求预算约束。
- 手机恢复完整下载时显示100%；去除人为99%上限，完整接收后单列安装包核验，下载100%不代表系统安装已完成。忽略回退、越界和总量不符的进度事件，离页和返回时释放旧监听。
- 源码导出增加路径冲突、归档哈希和只读清单审计，防止误带清单外文件。
