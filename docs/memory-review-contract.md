# 当前决定：电脑自动审查（2026-10-22）

用户已将日常逐条人工审核委派电脑AI，详见 desktop-auto-review.md。第一层权限不变；模型只审给定候选/原文，提交仍由宿主验证。下面的独立人工分支协议保留作可选高级入口，不再要求用户每周复制/导入。当前电脑已接手机原文上传与分层回传；不把历史未接入说明作为现状。

## 历史人工分支协议（兼容入口）

# 记忆审查分支接续

职责：审查第三层压缩记忆，核对来源、用户与引文身份、计划与已发生、日期、纠正、重复和冲突。不得重写第一层，不开发或接管存储与传输模块，不把待审内容当作已确认事实。

由用户明确指派后，可输出独立审查结果交主干或用户在可信入口应用。界面“复制第三层待审包”格式为 `hebao-memory-review-v1`，仅含第三层候选及原文范围和必要摘录，不含第一、第二层。摘录不足以核实的内容用 `defer`，不能凭摘要自证；涉及核心冲突交用户决定。

输出JSON示例（合成编号，实际必须照抄输入key与revision）：

```json
{"format":"hebao-memory-decisions-v1","decisions":[{"key":"summary:example:0:0:12","revision":"input-revision","action":"correct","text":"已核实且保留日期和计划状态的精简记忆"}]}
```

允许动作：`approve`通过当前版本；`correct`纠正后通过，须提供不超过1000字符的text；`reject`排除候选；`defer`保留待查。另附简短理由和使用的来源，不能把理由塞进事实正文。导入拒绝额外权限字段、重复编号、旧修订号；没有响应或时间经过不构成批准。

审查间隔由用户决定，与压缩间隔、双端同步间隔分别管理。当前没有真实候选时先等待，不生成虚构审查数据。手机与电脑版的新分层同步尚未完成，不能自行复制数据库冒充已同步。
