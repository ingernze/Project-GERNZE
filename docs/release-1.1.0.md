# 1.1.0 审查修复

本轮针对外部审查 6 项 P1、5 项 P2 修复。验证结果由主干接回记录补充；不是手机真机或真实模型验收声明。

- 修复手机分层同步设置使聊天初始化中断。
- 发布器附着现有会话库，不再创建聊天实例或接管 owner。只有真实记忆变更才通过原 epoch 屏障使旧回复失效。
- 冲突摘要不进入上下文；旧审批不能绕过冲突隔离进入第二层。
- 手机第二、三层为同库不同存储区，条目、冲突和同步图一次严格事务提交；摘要、审批与同步使用同一写锁和提交前版本核对。旧第三层只迁移一次并保留原库，旧版写入通过 IndexedDB 版本升级阻断。第一层和第四层边界不变。
- 电脑书架可显示仅由配对设备带来的第二层记忆；保留来源日期，未知日期进入未归档，不编造日期。
- 公开构建默认简版人设与空基础，不扫描私人数据库、不覆盖原设定；私人构建必须显式选择。
- 补齐安装器自有 Java 源码和必要 Android/npm 构建元信息白名单。保留兼容用包名、存储键和协议标识。
- Android 公开发行使用不可调试 release；签名与已安装版本的兼容性单独核对。
- 修正额度连接标题和过时介绍。

未在本轮承诺：所有机型适配、手机后台即时提醒、浏览候选正式接入、真实双机同步及真实 API 语义效果。
