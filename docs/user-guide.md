# 莉宝使用指南

适用范围：当前 Windows 桌面启动版。核对日期：2026-10-09。以下按钮名称与现行源码一致；两处旧窗口提示的差异列在文末。

本机正式入口是 `D:\GERNZE\启动版\莉宝.exe`。GitHub 源码和供 AI 阅读的源码 ZIP 用于开发，完整启动包还需要人物资源；文字朗读另需声音模块、权重和参考音频。操作指南不代表手机版已经实现。

## 先用这五步

1. 双击“莉宝”快捷方式，或打开 `启动版\莉宝.exe`。
2. 桌宠出现后，在工作台左侧选需要的功能；工作台关掉后，从右下角托盘图标右键菜单选“打开工作台”。托盘图标也可能藏在小箭头里。
3. 想试听声音：先在托盘菜单取消静音，再到工作台“声音”点“打开固定语音”，选一句，点“试听选中”。
4. 想让莉宝照着文字说：声音 → 打开文字说话 → 照着文字说 → 输入文字 → 生成并播放。
5. 用完需要彻底结束运行：托盘右键 → 退出莉宝。

首次创建设置时默认静音、音量 30%、人物大小 2×。已有静音、音量、人物位置和功能设置继续沿用；人物大小每次启动恢复 2×。

## 启动与退出

`莉宝.exe`、同级 `_internal` 和已安装的 `可选模块` 要一起保留。迁移安装目录时先退出程序，再移动整个启动版目录。单独移动 EXE 会缺少依赖或资源。

| 你想做什么 | 操作 | 结果 |
| --- | --- | --- |
| 打开工作台 | 托盘右键 → 打开工作台 | 打开或恢复本机工作台 |
| 暂时不显示人物 | 托盘右键 → 隐藏莉宝 | 隐藏人物，停止当前动作和声音任务；程序仍在运行 |
| 重新显示人物 | 托盘右键 → 显示莉宝；也可双击托盘图标 | 恢复显示；不是重新启动一个进程 |
| 暂时不要声音 | 托盘右键 → 静音 | 停止当前声音；后续播放受静音设置控制 |
| 结束程序 | 托盘右键 → 退出莉宝 | 关闭自有声音引擎和工作台服务，保存个人设置 |

关闭工作台的窗口叉只关闭工作台，不退出桌宠。安装或移除模块期间，程序会要求先等操作完成再退出。

入场动画在每次启动莉宝进程后播放一次，同一进程内重开、刷新工作台不自动重播。动画约 4 秒；接住怀表、镜头开始拉远约 2.1 秒处触发开场语音。播放期间点“跳过入场”或按 Esc，会结束动画并停止这次入场声音。关闭程序后再次启动才恢复新一轮入场。

## 工作台从哪里进入

| 左侧入口 | 主要用途 |
| --- | --- |
| 首页 | 进入学习空间；“自带材料（可选）”用于导入自己的材料 |
| 学习 → 六级学习 | 复制教师提示词，回填网页 AI 的学习汇报 |
| 学习 → 学习进度 | 查看已保存记录、学习日期和主题 |
| 项目记录 | 手动保存项目约定、进展和检查结果 |
| 提醒 | 查看已有提醒 |
| 备份与资料 | 导出本地记录 JSON |
| 声音 | 固定场景录音、文字朗读、声音专用 API |
| 模块中心 | 查看模块状态、安装或移除可选模块 |
| 设置 | 浅色／深色主题；展开调整眨眼、摆腿和睡眠 |

侧栏“学习”可展开子入口；空间不足时点侧栏顶部“收起侧栏”。“新的学习”进入六级学习页，不会自动创建题目或提交记录。

工作台地址里的 `127.0.0.1` 指向本机，端口和本地会话随服务变化。日常从托盘打开，不依赖以前复制或收藏的地址。

## 六级复盘与学习记录

日常主流程是纸上练习 → 网页 AI 讲解 → 把汇报带回本地保存。学习模块初始为空白，不附作者的学习记录。

1. 打开“学习 → 六级学习”，点“复制学习提示词”。
2. 到你自己使用的网页 AI 粘贴提示词，再提交试卷情况、阅读材料或具体问题。
3. 复盘结束后，把网页 AI 的完整学习汇报复制回来，包括其中的 JSON 汇报代码块。
4. 粘贴到“网页学习汇报”，点“保存学习汇报”。以页面的保存结果为准；只粘贴或离开页面不会保存记录。
5. 到“学习进度”查看本次记录。复制提示词本身不算完成一次学习，保存汇报才计入进度。

剪贴板不可用时，界面会选中提示词全文，按 Ctrl + C 复制。同一份汇报重复保存不会重复增加次数。未保存的汇报草稿可在本次工作台会话中切页继续，刷新或关窗后需要重新粘贴；重要输入先自行保留。

已有材料可在首页展开“自带材料（可选）”：粘贴文字后点箭头“开始学习”；或点加号“导入文件”选择 `.txt`／`.json`，选择文件后立即导入。导入文件限制为 500 KB。这是可选入口，不是纸质复盘的必做步骤。页面另有“导入示例”，仅在你主动点击时导入演示材料。

保存时报格式错误，按提示检查完整汇报及 JSON 内容，不把错误文本当作已经入库。历史只作为参考，不等于本次答案已经核验。

## 人物大小与美术

按住人物拖动鼠标可调整位置。普通大小在托盘菜单“人物大小”选择 1×、2×、3×。

切换美术：托盘右键 → 开发者：人物风格 / 语音 → 选择人物风格。目前“第一套 · 插画（默认）”是主要美术，“第二套 · 像素（备用）”保留试用。声音第一／第二套是另一套编号，与美术选择无绑定关系。

该窗口“开发者尺寸试看”提供 4 倍、5 倍和“2倍 · 恢复”。大尺寸仅用于试看；重启恢复 2×。

当前插画已接入静息呼吸、随机眨眼、拖拽、睡眠和低头摆腿；看书、四向走路尚无对应完整插画资源。像素备用保留已有的看书与走路。菜单中有动作入口，不代表所有画风都有该动作；缺少匹配资源时按界面提示处理。

## 调整眨眼、摆腿与睡眠

入口：工作台 → 设置 → 调整眨眼、摆腿与睡眠。平时面板收起，需要时点击展开。

1. 修改开关、时间或数值。
2. 点“保存动作设置”。看到已保存提示后，新参数生效，重启保留。
3. 想回到默认：先点“恢复默认值”，再点“保存动作设置”。恢复按钮只是填回默认参数，不会独立保存。

| 项目 | 默认值 | 含义 |
| --- | --- | --- |
| 插画待机眨眼 | 开启，3～5 秒 | 按呼吸循环衔接触发，实际间隔略有浮动 |
| 插画随机摆腿 | 开启，平均 20 分钟；1～3 轮随机 | 进入、结束各一次，中段只重复摆腿 |
| 自动睡眠 | 开启 | 只在资源可用的静息待机时触发 |
| 睡眠高发时段 | 22:00～次日 08:00 | 平均等待 10 分钟 |
| 其他时段睡眠 | 平均等待 120 分钟 | 不是每两小时固定入睡 |
| 一次睡眠时长 | 随机 30～600 秒 | 从坐下后计算，到时完成当前呼吸循环再自然醒来 |

“平均间隔”表示随机频率，不是到点必做。走路、拖拽、看书、睡眠、隐藏等状态会限制动作触发；恢复可用状态后不补播错过的动作。

眨眼间隔可填 1～120 秒，睡眠时长可填 1～3600 秒，平均间隔可填 1～1440 分钟，摆腿轮数可填 1～3。最短不能大于最长、最少不能大于最多；相等可用。错误范围会标记字段并阻止保存，原有设置继续生效。睡眠高发时段支持跨午夜，开始与结束不能相同。

关闭自动睡眠或随机摆腿，只影响后续触发，当前一轮不会因此强行中断。手动试看睡眠的入口是托盘 → 开发者：睡觉 / 摸头预览 → 摘帽睡觉；手动睡眠要用“醒来戴帽”结束，不使用自动睡眠时长。需要取消试看可点“停止并回待机”。

## 固定场景语音

入口：工作台 → 声音 → 打开固定语音。这是已收录录音的播放和场景设置，不需要聊天 API，也不加载文字合成模型。

选中录音查看台词、实际触发位置和时长，再点“试听选中”或按 Enter；用“停止试听”结束。当前本机收录 21 条，默认有 17 条场景绑定、4 条仅供试听。后续数量以窗口实际列表为准。

声音大小在该窗口调节，修改立即保存。默认 30% 表示相对原播放基准的三成，不等于 Windows 系统音量，也不等于听感一定减少到三成。Windows 音量、程序音量与托盘静音都会影响能否听到。

想换某个场景的录音：

1. 点“触发设置”，选择要修改的场景。
2. 点击录音多选。同场景多选时，每次触发随机选一句；全不选时该场景不播放声音。
3. 点“保存这个场景”。只保存当前场景；切换场景保留窗口草稿，关闭窗口不会保存未提交的选择。

“关闭本场景声音”和“恢复本场景默认”会立即保存当前场景的结果，无需再点保存。绑定录音不会新增美术动作，也不会让未接入的看书自行运行。

## 输入文字让莉宝说话

入口：工作台 → 声音 → 打开文字说话。窗口打开后由你操作，不会自动合成或播放。

1. 选择“照着文字说”。
2. 分别选择“GPT 权重”“SoVITS 权重”“参考音频”。下拉选择立即记住；日常优先使用同一套声音的配套权重和参考。
3. 输入 1～500 字，点“生成并播放”，也可按 Ctrl + Enter。
4. 需要取消时点“停止 / 取消”。关闭文字窗口也会取消当前任务。

首次使用要加载模型，比随后生成等待更长。进度条表示正在处理，不提供精确剩余秒数或虚构百分比。取消后旧结果不会延迟补播。

两套声音按时间顺序叫“第一套”“第二套”。它们是音色候选，不是美术编号；GPT 与 SoVITS 各有选择项，参考音频也单独选。已有选择继续沿用。

当前本地合成使用 NVIDIA CUDA 环境；没有自动 CPU 降级路线。只试听固定录音不需要加载该模型。声音引擎用完后空闲约 120 秒退出并释放自有模型；等待期间保留显存是正常驻留。需要立即结束自有运行资源时，从托盘退出莉宝。

## 接声音专用 API

这里的 API 用于让聊天模型回复你输入的话，再由当前本地声音朗读回复。“照着文字说”与固定录音均不需要这份聊天 API。

1. 工作台 → 声音 → 打开声音 API 设置。
2. 设置“启用声音对话 API”，填写“完整接口地址（以 /chat/completions 结尾）”“模型名称”和“API 密钥”。地址及模型名由你的服务商提供。
3. 点“保存设置”。密钥留空会保留已保存密钥；需要删除时用“移除已保存密钥”。
4. 回到文字窗口，选择“API 回复后说”，输入想问的话，点“生成并播放”。“查看 API 回复”用于查看本次返回的文本。

打开或保存 API 设置不会发聊天请求，实际请求发生在 API 模式生成时。该配置仅作用于声音对话，不给所有功能统一绑定同一个 API，也不代替网页 AI 学习流程。当前每次发送本次输入，没有自动连续聊天历史或长期记忆。API 回复后仍由本机引擎合成，需要已安装声音引擎。

当前回复超过 500 字会报长度错误，不会直接朗读。点停止后本机取消播放和后续处理，已经发给服务商的请求仍要等待返回或超时；停止不等于撤回远端请求。

密钥保存在本机 Windows 凭据管理器，不放在源码或学习记录备份里；关闭程序不会删除已保存的密钥。

## 导入一套成品音色

导入前先安装“本地文字转语音”模块。这里只导入已经训练完成的声音，不启动训练，不下载整合包。

1. 建一个名称清楚的文件夹，放入同一套声音的一个 GPT `.ckpt` 和一个 SoVITS `.pth`。不要混入多个训练轮次。
2. 配套参考音频使用 3～10 秒 PCM WAV；同目录放同名 `.txt`，写音频里的逐字文本。默认参考语言中文；英文、日文可另提供 `reference.json`，按导入说明填写文本和语言。
3. 将整个文件夹拖到 `D:\GERNZE\voice_engine\导入声音.cmd`。这个入口会转到已安装的独立声音模块。也可将文件放到 `启动版\可选模块\voice_engine\模型导入` 后双击模块内的 `导入声音.cmd`。
4. 显示导入成功后，退出并重新启动莉宝，再到文字窗口分别选择新增 GPT、SoVITS 和参考音频。

导入包没有参考音频时，可以沿用目录里已经有效的参考；没有任何可用参考时，文字窗口无法使用。对应原声和逐字文本能明确当前音色的参考条件。工具不会替你猜转写；同时有 `reference.json` 与同名 TXT 时，JSON 优先。

当前导入接收兼容 V2 Pro 系列的完整 GPT，以及 32 kHz V2 Pro／V2 Pro Plus 完整 SoVITS，不接收任意其他版本、LoRA 增量或训练中间检查点；格式识别通过不等于任意来源模型都已完成实际合成验收。权重提供者仍需确认两份文件属于同一套音色，结构校验不能替代这项配套确认。

相同权重内容会复用已有条目，不重复复制。相同名字但不同权重内容可新增条目，显示名会重复，所以不同音色用不同名称的文件夹更清楚。导入保留原输入文件，不覆盖现有音色；相同参考 WAV 改了转写或语言时会拒绝导入，按提示核对其转写与语言。

## 安装与移除模块

基础桌宠与工作台单独运行，三类模块按需安装：中国英语六级学习、固定场景语音、本地文字转语音。

1. 工作台 → 模块中心，在“六级学习”或“声音”项点“安装与移除”。未安装的学习页也提供“安装与移除模块”。
2. 模块窗口点“选择模块 ZIP 安装”，选择与当前发行版配套的莉宝模块包。不是任意素材 ZIP 或 GPT-SoVITS 整合包。
3. 等待校验、整理完成。回到模块中心点“刷新状态”查看结果。
4. 不再需要某项功能，在模块窗口点该项“移除模块”，确认后等待完成，再刷新状态。

生成语音时先点停止，再安装或移除模块；操作期间不要移动相关目录。模块移除保留个人记录、设置和已导入音色，移除功能不等于清空你的数据。再次使用需要重新安装对应模块，已有本地个人资料按保留规则接回。

原个人数据库留在原位置；模块里新增或改动的文件保留到数据目录的 `module_retained\模块ID`。重新安装声音引擎会接回保留的模型、参考音频、状态和音色清单，并非把所有输出或任意修改文件都自动放回原处。功能恢复方式是重新安装配套 ZIP，没有独立“恢复已移除模块”按钮。

## 项目记录、提醒与备份

“项目记录”用于手动保存项目事项，不是自动聊天记忆。填写“标题”“正文”，选择“候选想法”“已采用”“待定”或“不采用”，点“确认保存项目记录”。成功后输入清空，新记录显示在下方；当前工作台没有编辑或删除记录的按钮。

工作台“提醒”页目前用于查看已有提醒，不提供创建或取消按钮。需要管理提醒，从托盘“提醒与资料工具”进入“提醒与备份”页。学习模块未安装时，该入口先打开模块安装窗口。

1. 填“提醒内容”和本地时间，例如 `2026-10-09 20:00`，点“保存单次提醒”。
2. 要收到通知，再打开“启用提醒（当前程序运行期间）”。保存提醒不会自动启用通知；每次重新启动程序，通知默认关闭，需要自行启用。
3. 取消时先选中提醒，再点“取消选中提醒”。
4. “安静模式（到期暂存，解除后集中显示）”暂存到期提醒；关闭安静模式后集中显示。关闭工具窗口不停止已启用提醒，退出莉宝停止本轮运行。

“刷新 / 恢复后核对时间”刷新提醒列表和调度时间，不是恢复备份的按钮。学习汇报不会自动创建提醒。

工作台 → 备份与资料 → 导出 JSON 备份。文件由浏览器保存到下载位置，包含阅读材料、学习提交、项目记录、提醒和交接信息。它不包含声音模型、运行环境、API 密钥或整套程序；工作台尚无一键恢复 JSON 的入口。

原工具“提醒与资料工具 → 提醒与备份”还提供“导出全部数据 JSON”和“备份数据库”。它们弹出另存为窗口，选择尚不存在的新文件；数据库备份保存为 `.sqlite3`。当前没有一键恢复数据库按钮，恢复旧备份需完全退出程序、先另存当前数据，再进行手动维护；旧备份对应的是旧时点的记录。

正式 EXE 的设置、学习记录和运行日志默认位于 `%LOCALAPPDATA%\HecatePixelPetDeepSeekTrial`。按 Win + R，粘贴这个路径可查看目录。正常关闭或重新启动莉宝不会删除这里的数据；删除启动目录也不等于自动删除该数据目录。

默认数据库是该目录下的 `modules\hebao_modules.sqlite3`。上述位置针对正式 EXE；开发时使用自定义状态目录的，以该目录为准，不把开发测试数据当作正式记录。

需要保留个人设置、学习记录和运行日志时，先退出莉宝，再把该数据目录另存备份。个人设置和数据库备份与可选声音模块、原稿素材分开保存。记录备份也包含你的个人内容，留在自己的备份位置；GitHub 继续只收录审查过的源码白名单。

## 常见问题怎么处理

| 现象 | 先做什么 |
| --- | --- |
| 工作台提示 127.0.0.1 拒绝连接／本地会话无效 | 确认莉宝仍在运行，从托盘重新“打开工作台”，使用新打开的地址；仍失败则正常退出再启动一次，保留错误截图 |
| 按播放没有声音 | 显示莉宝、取消托盘静音，确认程序音量大于 0，再检查 Windows 音量与输出设备 |
| 文字朗读提示未安装／缺模型 | 确认本地文字转语音模块已安装，GPT／SoVITS 与参考音频确实可选；依提示补配套文件，不把固定语音模块当合成引擎 |
| API 不能回复 | 核对开关、完整接口地址、服务商模型名和密钥；“照着文字说”用于区分聊天接口与本地声音问题 |
| 设置保存不了 | 看标记字段；检查最短≤最长、最少≤最多、高发时段起止不同，按字段单位填写 |
| 自动动作没有到点发生 | 这是待机时的随机频率；先确认动作开关、人物可见及对应画风资源，等待原地静息状态 |
| 模块状态没更新 | 模块操作完成后回到模块中心点“刷新状态” |
| 显存暂时没有立即下降 | 停止新的语音任务，等待约 120 秒空闲释放；需要结束所有自有任务时退出莉宝 |

持续报错时记录所在页面、按钮、完整错误和发生时间。正式程序事件日志在数据目录的 `output\app_events.jsonl`；先保留这些证据，不通过清空个人数据来尝试修复。

若文字窗口提示“语音未完成，请检查独立后端日志”，查看 `启动版\可选模块\voice_engine\state` 下的日志，区分模型加载、参考音频和显卡环境错误。

## 人物页记忆（本机，2026-10-16源码）

进入人物场景，展开聊天区下面“记忆（本机）”。填写标题、正文、类型，日期可留空；点“保存记忆”后重启仍在。每条最多500字，有效记录最多100条。勾选“用于聊天”的内容会随显式发送的问题交给你选择的聊天API，最多6条；“重要”会排在前面。保存、查看和纠正本身不会请求聊天API，但带入记忆的聊天会增加输入内容和相应token。

点记录下方“纠正”修改，保存后替换当前版本；“忘记”需再点一次确认，会清除该条本机正文并保留无正文的同步删除标记。纠正/忘记会清空当前短期对话，旧在途回复不再补回来；不会撤回此前发送给服务商的内容或删除其他设备与备份。页面提示“本次带入的记忆”只表示提交了哪些参考，不证明模型实际引用了每一条。

本轮是手动管理记忆，不会从闲聊自动提炼偏好、训练模型或后台反思。热点真机连通已通过，真实记忆同步仍未接入；当前EXE和手机安装包也尚未随源码更新。项目记录入口继续用于项目事项，与这里的个人陪伴记忆分开。
