# 代码与素材的使用范围

作者已于 2026-10-20 选择：**源码可见，允许个人非商业使用、修改和免费分享；商业使用需事先另行取得书面许可。** 完整条件见仓库根目录 [LICENSE](../LICENSE)。这是项目自定义非商业许可，不标成 MIT、GPL 或标准开源。

| 内容 | 当前使用范围 |
| --- | --- |
| 本项目有权许可且未另标许可的代码和技术文档 | 按 GERNZE 非商业代码许可 1.0；分享时保留许可、版权及来源，修改版说明修改情况 |
| 插画、图标、动画、录音、模型、权重与完整角色设定 | 不包含在代码许可中；使用和分发分别遵守相应授权，不因代码可见而自动获准提取或再利用 |
| 第三方代码和资源 | 保留各自原许可及声明；见[参考与复用清单](reuse-and-attribution.md)，不能用本项目许可替换原许可 |
| 个人记忆、聊天、密钥和配对资料 | 不发布，不作为代码包或可选插件的默认数据 |

例如：个人可修改骨架，使用自己有权使用的角色素材，再免费分享修改版，并附上对应许可与来源说明；将修改版售卖、增加付费功能或集成到有偿服务，需要另行授权。私人修改不要求公开。个人支付自己的 API 费用不属于销售本项目。

骨架和 Codex 插件中的本项目代码适用同一范围，不因分成独立下载而变成另一种许可。现有第三方插件和依赖仍按其各自许可处理。安装包的下载和运行不授予单独分发其内素材的权限；发行者必须在发布前确认所包含资源可合法分发。

此选择只用于本次及后续明确采用该许可的发行，不能撤回以前已经有效授出的其他许可。仓库中的历史研究笔记提到 MIT/GPL 等，通常是在说明第三方项目，不是本项目改用那些许可。

许可概念与标准开源的区别参考 [GitHub 许可证说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) 和 [Open Source Definition](https://opensource.org/osd)。本页是使用范围说明，许可正文以 LICENSE 为准。
