# 独立研究测试版

这是源码试用入口，沿用当前工作台和美术，不替换已安装的电脑版或手机版。用于试用研究书架、资料选用、带来源聊天和独立核对。

## 打开

在项目根目录双击“启动研究测试.cmd”。需要已安装requirements-desktop.txt中的桌面依赖。本轮在维护电脑核对到Python 3.12.9，Pillow、win32gui与win32cred可导入；没有据此宣称真实窗口已经验收。

也可在项目根目录运行：

```powershell
python -B src/research_preview.py --profile "D:\你的独立测试目录" --samples
```

目录必须是新的空文件夹，或该工具已经创建的测试目录。根目录启动脚本默认使用local-notes/research-preview，不读取或迁移原版聊天库。窗口标题和右上角标为“研究测试版”。关闭这个窗口后，原版照常使用；无须把测试库覆盖回去。

## 先试什么

1. 在测试窗口的设置中单独配置聊天连接。这里只显示密钥是否保存，不显示内容；测试版对所有连接的密钥读、写和删除都使用独立命名空间。
2. 打开人物场景的记忆书架，先显示原来的月册、封面和立体书架；没有已保存对话时显示空书架，不伪造月册。右上角“分类资料”可查看四组资料，再选“按日期翻看原文”回到月册。使用 --samples 启动时另有两份明确标注“测试样例”的合成资料，分别用于普通研究和课程入口，不代表你的真实经历或课程。
3. 从见闻分组选择一份“用于下一次提问”，查看输入区的所选提示，再发送问题。也可先移除，检查普通提问不携带这次选择。
4. 课程资料需从课程分组明确选用。通用研究入口不能替它授予课程用途。选择消耗不等于删除原文；普通研究已有对话仍按有效来源和依赖规则参与上下文。

启动本身不发送模型请求，自动审查每次启动均暂停。可先手动检查效果，再按需开启自动审查。手动聊天、摘要或审查仍会使用你配置的服务；思考等级与8192/60秒的核对预算沿用既有实现。本入口不启动手机更新，当前只供电脑版研究试用。

## 资料和连接

测试目录内保存research-preview.json身份标记、workbench会话/研究库及独立浏览器临时资料目录。目录和标记共同确定密钥命名空间；把标记复制到另一路径也不会共用同一命名空间。采用原有Windows凭据存储，不新增明文密钥文件。这是本工具的命名隔离，不是新的操作系统访问权限隔离。

人设及第一层只读资料沿用当前源码目录已有文件，缺失时按原有模板/报错规则处理；不复制原版聊天、已审记忆、连接配置或Agent库。测试样例只在首次缺少对应条目时添加；撤回、修改或不可用的既有样例不会在重开时被恢复。样例原文保留合成来源和未核验标记。

已有普通v1会话库或不兼容研究库不得直接放进测试目录升级。单进程运行期间复用现有文件锁，避免另一CLI实例同时接管同一测试资料。链接/联接目录拒绝作为测试资料或浏览器目录。不要把这个测试目录或凭据加入公开包；local-notes仍不在源码白名单中。

## 后续分类资料如何更新（2026-10-28）

维护电脑的独立研究目录已启用本地增量接回。分部完成一次已有授权的阅读/验收并维护完整资料包后，重新打开书架，或下次启动研究测试入口，就会核对并接回新增与修订；不需要再次逐包导入。此前月册美术和聊天记录继续沿用。此流程不发起新阅读，也不调用模型。

默认配置关闭。独立研究测试宿主需在已验收的独立研究资料目录放置bookshelf-receipt.json；2026-10-29起，普通日用宿主也可在现有资料目录由匹配的本地回执启用仅书架同步。format为gernze-bookshelf-receipt-v1，profileId匹配对应目录身份，namespace和source固定，sourceKind为saved_reports_not_original_webpages，courseMapping存宿主批准的课程UUID，明确设置automaticSync为true。来源里的建议课程编号不能给自己授权。该接法不启用研究聊天，不迁移原聊天库；回执和资料不进入公开源码包。

来源需包含libao-reading-shelf-v1分类索引与libao-reading-shelf-host-map-v1映射清单，映射仅列活动导入包。索引声明总数、活动项、分片及包哈希必须一致，长文能完整拼回；错过的修订由显式修订历史逐步补齐。单包沿用现有4MB/100项限制；整次读取32MB、至多128包及每片32个前序版本，超限须先整理交付。宿主将整次导入与失效处理放在同一事务，提交前重验文件。文件还没齐、版本断开、分类/课程变化等情况保留旧库并在书架提示，下次打开重试。

活动清单不再包含的来源或尾片会标为不可用，原文和导入历史保留；本机修改、撤回及冲突继续保留，不靠重导自动复活。恢复这些资料或改变已有权限需另行核对。同步只保存研究资料，课程正文仍须通过明确的课程查看/学习用途入口；不会直接变成已审记忆。
