# 给移动端评估AI的交接说明

日期：2026-10-09。用户希望你依据当前莉宝源码评估手机版。本轮交付源码和结构说明，不代表已有Android／iOS实现。先读 [结构地图](architecture.md)，再按下表读取目标模块。

## 先确认产品形态

工作台App（应用内学习、设置、角色与声音）和跨应用悬浮桌宠是两个不同目标。先向用户确定目标平台Android／iOS及是否必须跨应用悬浮；分别核对平台权限、前后台生命周期和商店分发规则，再给选型依据。不把Windows托盘、透明窗口或后台常驻逻辑直接复制到手机。

## 哪些逻辑可以作为迁移依据

| 部分 | 可复用的内容 | 必须适配的边界 |
| --- | --- | --- |
| 工作台页面 | HTML/CSS/JS、主题与模块注册、有限JSON命令 | 小屏、触摸、软键盘、安全区、移动返回行为；选择移动壳后适配通信层 |
| 学习流程 | 教师提示词、汇报格式、解析校验、进度定义 | 宿主实现、手机存储路径、粘贴／分享／导入导出 |
| 数据 | SQLite表结构、事务与迁移语义、JSON设置格式 | 手机平台的数据库API与存储目录，不复制作者数据库 |
| 动作 | 帧顺序、时长、锚点、资格判断、随机频率 | 渲染器、触摸拖拽、定时与后台恢复、设备密度和图片缓存 |
| 模块边界 | 三类模块ID、版本与校验、移除保留数据的规则 | 当前实现安装Python文件；移动分发和可执行代码安装规则需重新设计 |
| 固定语音 | 场景ID、绑定方式、音量和播放／取消语义 | Windows音频API替换为移动播放器，音频焦点和中断处理 |
| 外部API | 功能独立配置、回复文字再合成声音的链路 | 系统安全凭据、请求取消、网络状态与隐私说明 |

可复用是指业务规则、数据契约和已独立的代码逻辑；不表示所有Python文件能原样在手机运行。前端是否复用取决于用户选定的移动实现。

## 已确认的Windows／GPU耦合

- `app.py`、`desktop_main.py`、`tray_win32.py`、`win_bridge.py`及部分窗口控制使用Tkinter、pywin32、Win32／ctypes接口。
- `workbench_window.py`启动电脑上的Edge／Chrome应用窗口，不能当作手机WebView宿主。
- `credential_store.py`及声音API存储使用Windows凭据管理器；手机必须使用对应安全存储接口。
- `scene_voice.py`使用Windows音频播放；`engine_worker.py`使用msvcrt进程锁。
- 当前GPT-SoVITS worker显式要求CUDA，并拒绝自动切CPU，使用runtime/python.exe。它不能直接作为手机本地语音引擎。评估手机调用用户电脑／独立服务的合成接口、移动系统TTS或单独适配的移动推理；给出音色、离线性、延迟、流量和部署差异后由用户选择。
- `build_modular_release.ps1`、Windows系统C#编译器和PyInstaller桌面发行用于当前Windows包，不能生成APK／IPA。
- 当前工作台服务监听127.0.0.1。手机上的127.0.0.1指向手机自己，不会连接用户电脑。连接电脑服务需要明确地址、认证、加密及服务边界，不能只替换URL后开放端口。

## 保留的产品约定

中国英语六级模块默认空白，用户纸上做题后在网页AI复盘，再由用户回填汇报。不要改成默认自动出题、自动读取网页或自动创建提醒。

固定场景录音与动态文字合成分开；API按功能独立配置。美术第一套插画默认，第二套像素备用；声音权重编号独立。

记忆／自我迭代、内部MCP和Codex监测升级仍暂缓。现有项目记录不是自动长期对话记忆，不借移动迁移自行新增这些功能。

## 你应交回什么

1. 平台和应用形态的确认结果。
2. 成熟项目与官方框架实现依据，比较适合本项目的移动路线；不因名字流行就选框架。
3. 按文件或模块划分“直接复用／改通信适配／重写／暂不支持”，列出具体入口和依赖。
4. 首版范围、原型验证顺序、安装包和资源体积估算，以及声音是否依赖电脑或外部服务。
5. 验收方案：首次启动、触摸／软键盘、数据重启保留、前后台切换、音频中断、接口失败、权限拒绝及资源释放。

先完成评估和方案，用户确认后再实施手机版。源码仓库保持私有；另一个AI需获授权访问仓库，或者使用本次导出的源码包。个人记录、密钥、训练数据和声音权重不作为交接输入。
