# 1.1.1 更新说明

## 本次变化

- 接回电脑版独立自动记忆审查、旧同步来源修复和审核事务修复。普通聊天/摘要API仍只能形成第三层；独立的电脑审查流程只对照待审摘要及对应原文，批准具体版本后进入第二层，不读取第一、二层正文用于审核，不自动改写或恢复既有第二层。
- 自动审查默认开启，可关闭；工作台运行期间检查排期，默认7天、最短1天，留空可暂停定期审核，一次最多3条。已配置服务、有候选且达到条件时才发起审核请求，会消耗配置服务的相应额度；工作台关闭停止。
- 自动晋级要求完整用户消息及有限句式准入。明确小说、引文、假设或不支持的自由表达继续待审；会漏收正常事实，也不能保证辨认未标记的虚构内容。
- 手机带入同步来源校验及记忆状态说明的最新修复；仍由电脑统一审查，手机只接回第二层结果。
- 手机版开场右下角新增小号 `v1.1.1`，与既有元素一样淡入并轻微上移；支持减少动态效果设置，避开底部/右侧安全区。构建时读取Android版本，避免以后显示旧版本。
- 版本名为1.1.1，Android构建码30。代码采用自定义非商业许可，素材及第三方许可另行处理。浏览模块仍为独立候选，学习/六级新开发继续暂缓。
