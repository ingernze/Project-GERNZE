# 莉宝 Codex 接入模块

复用现有Codex聊天及工作工具，通过本地stdio MCP读取角色资料和许可范围内的记忆。需要用户授权当前聊天使用后才留底；不扫描其他聊天，不另调用付费模型。接口和当前未接通部分见[CONTRACT.md](CONTRACT.md)。

## 分发方式

用户确认以独立可选插件提供，放在同一项目发布页的骨架下载入口下方。骨架安装包不携带、不自动下载此插件；源码仓库仍可以包含这部分通用源码。完整私人人设、用户资料、真实记忆库和settings.local.json不随源码或插件发布。

## 可安装插件

plugin/内已提供独立插件结构、MCP入口、原Skill、基础空白资料，以及安装/卸载入口。下载分发包后按插件README操作；依赖与个人库位于LocalAppData/GERNZE/CodexPlugin，插件缓存不是资料存储位置。支持从明确配置的桌面会话库只读读取第二层，仍不授予改写上层的接口。

可选完成提醒使用宿主Stop事件；首次信任由宿主要求用户确认，不更改全局notify。卸载保留个人资料和其他MCP/Skill。该轮按用户要求未做安装、事件或手机验证。

第一、二层经本模块接口只读，第三层为有来源的待审摘要，第四层为明确授权对话的原文留底。接口边界不等于操作系统级隔离；其他工作工具仍遵守其宿主权限。

官方参考：[插件打包](https://developers.openai.com/plugins/build/plugins)、[安装/移除命令](https://learn.chatgpt.com/docs/developer-commands)。GitHub最后提交和发布由用户操作。
