## 提醒行为

用户主动保存时才请求通知权限。拒绝时不会显示“系统提醒已保存”，其他功能保持可用。修改提醒保持同一个系统编号。关闭或移除都取消系统安排。点击通知返回学习页。已发送通知的回调不会重复显示前台提示。

普通返回桌面不依赖人物继续播放。划掉最近任务、设备省电和厂商后台管理的具体效果需在目标手机上检查。设置中的“强制停止”会停止系统安排，重新打开时重新安排尚未到期且已开启的提醒。权限被撤销时不自动弹框要求重新授权。

官方组件有开机恢复接收器：恢复已保存安排，跳过已经触发的一次性通知；手机关机期间错过的安排由组件在解锁后的恢复流程中处理。这是源码核查结果，尚未在华为手机实测。系统调度是非精确提醒，不能保证到秒。

## 构建

需要 Node 22+、JDK 21、Android SDK 36 和对应 Gradle。首次执行 `npm ci --ignore-scripts` 安装固定依赖，然后执行 `npm run build:web`、`npx cap sync android`。设置当前构建进程的 `JAVA_HOME`、`ANDROID_HOME`，在 `android` 目录执行 `gradlew.bat assembleDebug --no-daemon`。

构建工具、SDK、缓存和签名文件不复制进手机安装包，也不加入源码上传清单。当前候选为调试签名测试包；正式分发签名与发布另行处理。网页素材是当前本地使用的美术，没有个人学习数据库、账户凭据或参考 Live2D 模型。
