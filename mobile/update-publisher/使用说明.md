# 手机内更新

电脑连接手机热点后，双击“打开电脑更新.cmd”，确认电脑地址，点“开始发布”。
手机莉宝进入“设置 → 电脑更新”，首次扫描电脑二维码，核对电脑窗口身份指纹后配对。
以后这台电脑保持相同地址和发布端口，手机直接检查、下载并点系统确认安装。
电脑地址变化时刷新配对码并重新扫描。二维码180秒有效，不给其他人。
关闭窗口会停止发布；不会自动开机启动或让人物后台常驻。

首次带接收功能的手机版仍需手动安装。发布相同版本时显示已经是最新版；只有主干发布更高版本才进入下载/安装。
配对凭据和一个最新文件快照位于本目录 .state，已从Git忽略，不随任务包或仓库上传。
当前仅完成工程与本机测试，手机相机、热点和系统安装需要真机确认。
