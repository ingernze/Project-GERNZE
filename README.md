# 赫宝（Hecate）

当前为私有仓库准备阶段的源码。项目介绍留到公开前由作者撰写。

桌面入口：`src/deepseek_trial.py`。模块化构建：`src/build_modular_release.ps1`。工作台接口：`src/workbench/server.py`。

代码包含桌宠、工作台、动作调度、模块安装、六级复盘与声音接口。六级分发初始化为空白；学习材料由使用者自行导入。本源码不包含作者的数据库、凭据、音色权重、录音、人物素材或运行环境。

这是源码仓库。直接运行桌宠或构建EXE还需要兼容的运行素材；声音合成另需独立推理环境和模型。基础EXE与可选模块分别分发，仓库中的源码不等于完整安装包。

文件清单见 `source-files.json`，内容边界和构建条件见 [源码说明](docs/source-package.md)。
