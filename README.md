# 赫宝（Hecate）

当前为已上传的私有源码仓库。首次源码版本为 `c6b369e`；用户随后亲自提交并上传 `6090fe9`，添加第一套插画的正式待机图 `src/assets/styles/style2/F00.png`。仓库私有状态以用户提供的 GitHub 页面截图为依据；本次文档更新没有改变仓库可见性。正式项目介绍由作者在公开前撰写。

桌面入口：`src/deepseek_trial.py`。模块化构建：`src/build_modular_release.ps1`。工作台接口：`src/workbench/server.py`。

代码包含桌宠、工作台、动作调度、模块安装和移除、六级复盘与声音接口。六级分发初始化为空白，学习材料由使用者自行导入。中国英语六级学习、固定场景语音、本地文字转语音分别作为项目支持的可选模块。

美术第一套为插画（默认，内部标识 `style2`），第二套为像素（备用，内部标识 `original`）。声音第一套／第二套按音色权重时间顺序命名，与美术编号独立。

仓库目前只收录一张人物待机图，未收录完整动作素材、声音模型、录音、作者数据库、凭据或运行环境。直接运行桌宠或构建 EXE 仍需补齐匹配资源；声音合成另需推理模块、配套权重和参考音频。基础 EXE 与可选模块分别分发，源码仓库不等同于完整安装包。

文件清单见 `source-files.json`，内容边界和构建条件见 [源码说明](docs/source-package.md)。功能地图和操作说明整理尚未完成；内部 MCP、记忆与自我迭代、Codex 网页／桌面监测升级继续暂缓。
